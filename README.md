# interactor-test-fbx

Third-party `.fbx` models and animations, each with a JSON record of its title, author, source and licence, for testing scene importers.

## What it is for

Each subdirectory is one source collection, brought in as a git subrepo from its own repository. A model sits beside a JSON file naming its author, source page and licence, so a test can attribute what it loads.

## Use

The models are data, so there is nothing to build.
